# SCSE3040 MLOps Practical 02

## Your First Honest Model

This practical focuses on predicting food delivery time using Linear Regression and comparing the model against a baseline.

### Topics Covered

- Loading and viewing the delivery dataset
- Separating features and target
- Train-test split
- Mean and median baseline
- Linear Regression
- MAE and RMSE
- Model coefficients
- Prediction of a new order

### Tasks Completed

- T1: Median baseline MAE and comparison with mean baseline
- T2: Linear Regression using a 70/30 train-test split with seed 7
- T3: Function to predict delivery time for a new order

### Result

The Linear Regression model beat the baseline by 81%.
